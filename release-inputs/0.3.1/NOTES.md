# RepoWeave 0.3.1

## Deutsch

- Editor: „＋ Einfügen“ und „B“ überlappen nicht mehr; die Werkzeugleiste scrollt horizontal.
- Einstellungen: Hell, Dunkel und Systemeinstellung; passende Markdown-Farben und Android-Systemleisten.
- Einstellungen: Deutsch und Englisch für die Oberfläche. Notizen, Dateinamen und Git-Daten werden nicht übersetzt. Entwürfe bleiben beim Sprachwechsel erhalten.
- „Updates suchen“ verwendet die öffentlichen Releases von `deospero/RepoWeave-Releases`. APK herunterladen und anschließend in Android öffnen.
- Fehlerbehandlung beim externen Öffnen großer Dateien bleibt in beiden Sprachen verfügbar.

**Installation:** `RepoWeave-0.3.1.apk` herunterladen und über die vorhandene App installieren. **Nicht vorher deinstallieren oder App-Daten löschen.** Paket und Signatur bleiben erhalten. Android 8.0 oder neuer, aktuelle Android System WebView empfohlen.

## English

- Fixed the overlap between “＋ Insert” and Bold in the editor toolbar.
- Added light, dark and system themes, including Markdown and Android system bars.
- Added German and English interface languages. Notes, file names and Git data stay unchanged; drafts survive language changes.
- Added “Check for updates” using this repository's public releases.

**Installation:** Download and open `RepoWeave-0.3.1.apk` to update the existing app. **Do not uninstall or clear app data first.** Existing package/signing identity is retained. Android 8.0+.

This is a directly installable development-signed APK, not a Play Store release.
